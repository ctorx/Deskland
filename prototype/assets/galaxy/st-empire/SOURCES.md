# Texture sources for the st-empire scene (Ice fortress)

All source textures come from Poly Haven and are licensed CC0 (public domain dedication):
https://polyhaven.com/license

Each file below was built from the 2K JPG maps with Pillow. Every channel is a grayscale map
(converted to luminance, auto-contrast, resized to 2048 px). The files are saved as JPEG with
4:4:4 chroma so the channels stay separate.
